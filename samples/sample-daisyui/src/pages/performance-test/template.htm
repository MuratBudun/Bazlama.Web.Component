Property Changes

Direct assignment triggers property setters and change hooks immediately. More efficient for programmatic updates.

Attribute Changes

Triggers attributeChangedCallback which then updates properties. Better for HTML/template sync but slightly slower.

Manual Render

Property/attribute changes update hooks but don't re-render DOM. Use Manual Render button to force a complete re-render.
